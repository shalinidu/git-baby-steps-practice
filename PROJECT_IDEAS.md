# Project Ideas for Jira/Confluence Automation

## 1. Automated Sprint Health Dashboard
**Problem it solves:** Managers often lack a quick, consistent overview of sprint progress, making it hard to spot blocked work, scope creep, or uneven team load.  
**Data it needs:** sprint dates, issue statuses, story points, assignees, issue type, custom fields for impediments/risks, and sprint membership from Jira.

## 2. Risk and Dependency Tracker for Releases
**Problem it solves:** Release planning can miss important dependencies or surfaced risks, causing late surprises and delayed delivery.  
**Data it needs:** linked issues across epics/components, dependency relationship types, issue priority/severity, release target dates, and Confluence page references for risk descriptions.

## 3. Meeting Notes to Action Items Sync
**Problem it solves:** Managers spend time manually translating meeting notes into Jira tasks and tracking whether action items are assigned and completed.  
**Data it needs:** Confluence meeting note page title/content, identified action items, owner names, due dates, Jira project mapping, and existing issue relationships.
