# Python Calculator

A simple Python calculator project with basic add and subtract functions.

## Files
- calculator.py: Contains the add() and subtract() functions.
- main.py: Demonstrates how to use the calculator functions.

## multiply()

`multiply(a, b)` returns the product of `a` and `b`.

Usage examples:

```bash
# Run the demo script
python3 main.py
```

Or import in Python:

```python
from calculator import multiply
print(multiply(5, 3))  # 15
```
